## Brief checklist (Sam's asks)
- [x] 1. Exact who-uses-this tool `source/touch.py NAME`: defs with file:line, callers film vs shared, checks and kit
  tests that cover it, ~10 lines; rebuilt at session start (setup.sh, background, 7.5 s); stale index flagged by
  `handover.py end` (touch_faults). Kit test `touch_index` (example: grep misses the kit test passing
  `people.head_faults` as a value, and the callers' chain).
- [x] 2. RERUN line: after any edit to code a hook says the kit tests touching the changed functions (one line, only
  when it changes); `kittests.py --touching NAME` / `--changed` run just those. Never runs the suite.
- [x] 3. Step counter per note (`source/notesteps.py`, PostToolUse hook): 12 steps -> "say what is stuck", 20 (and every
  5 after) -> stop and report; finishing a fix allowed; overruns logged to notes/logs/notesteps.log. Kit test
  `notes_step_counter` (example: a chat-30-like 35-step note).
- [x] 4. One-page fix pack `guides/fix-pack.md` (729 words, ~1,000 tokens), named first in job-packs Notes round;
  `handover.py end` (fixpack_faults) refuses a fixing Next whose Read line lacks it. Kit test `fix_pack_named`.
- [x] 5a. MAP on every big file: 138 files of 150+ lines had none (176 of 318 counting tiny ones); generated by
  `source/maps.py` (the code itself proven unchanged, ast-compared); `handover.py end` flags a big file without a MAP
  or a generated MAP that no longer matches. Kit test `maps_on_big_files` (it caught the 9 new topic files at once).
- [x] 5b. kittests.py (7,341 lines) split by topic into 9 files (452-1,024 lines each) + the runner (about 800 lines):
  217 tests in the same order, every function's text identical (checked), stamps still valid (same keys);
  kitstamps, checkaudit, ruleproofs, toolhealth, watcher, handover and touch read all parts.
- [ ] 5c. The other 27 files over 1,500 lines: NOT split (see Open).
- [x] 6. Chain guard `.claude/hooks/chainguard.py`: create_session without `model` refused; `handover.py start`
  says STOP when this chat runs on another model than the notes' Next line names, and the hook says it again if
  the model switches partway. Kit test `chain_model_lock` (example: the 27 Nov Brexit animatic chat, Sonnet->Opus).
- [x] 7. `ledger.py appcost FILM USD --restarts N`: the app's figure (get_session) into app-costs.tsv and
  notes/ledger/app-check.tsv beside the estimate (main / helpers / other records apart); >25% under is flagged;
  `handover.py end` (appcost_faults) flags a cloud chat with no app figure. Kit test `app_cost_gap` (chat 36).
