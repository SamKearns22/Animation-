# The chat's own idea (written before the helpers run)
1. Make the finder the first move: the hook that notices a hand search of film code refuses it until `page.py show`
   has been tried for that note, and the finder also covers the shared tools.
2. A one-page tool map (job, tool, one command) loaded at the start of each chat, so tools are not hunted or loaded one
   by one.
3. The last chat of a film runs `ledger.py app` at handover so the real figures replace the guesses, and the film's
   running cost is shown against 15% at each stage.
Cost: about 1.5% of a week to build; aim: hand searches under 15% of round steps, tool loading halved.
