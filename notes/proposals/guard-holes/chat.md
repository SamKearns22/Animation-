- A question is a change if it carries a permanence marker ("every film", "every round", "from now on", "always",
  "each time", "all films", "in every") or a system noun (add the film-making parts: house look, subtitles, fps, sheet
  layout, critic pass, gate, step, sign-off) with an action verb (change, add, make, switch, update, remove).
- Routine words only pass a question when it has no permanence marker and names one film's thing (this animatic,
  shot 4, note 8, seconds 4-7).
- Drop bare "hook" from the change words (Hook Text); keep "Stop hook".
- The refusal no longer offers "reword"; it says: route it, or if it is truly one film's matter, say which film item.
- Beat: the probe file plus 20 real asks pulled from past chats' records (list_events): 0 change asks missed, at most
  1 routine ask stopped; kittest extended with both lists.
