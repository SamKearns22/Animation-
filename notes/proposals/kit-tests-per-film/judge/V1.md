# The chat's own idea (the draft Sam said Y to, R7 chat 4, 25 Nov)

1. The full kit run happens twice per film: in the film's first chat, and before its final render.
2. No full run when a machine starts, and none at a handover otherwise (the start-up background run and the
   handover's stale run stop).
3. After a big change to a shared kit, the chat suggests a full run to Sam in plain words and runs it only on his Y.
4. A new tool's own single kit test still runs once, when it is built.
5. kittest-resume is dropped (not built).
