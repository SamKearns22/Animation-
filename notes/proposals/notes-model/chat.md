# The chat's own version (written before the helpers ran)

1. A notes round where every note only changes words, timing, sound, a re-render or a move of a prop goes to Sonnet.
2. Any note that changes a look, a pose, a face, staging or a new build stays on Opus medium.
3. The deciding chat (Opus) sorts the notes into the two kinds and opens the Sonnet chat for the first kind.
4. The handover check flags a Sonnet round that took a look/pose note.
5. The end-of-film review compares repeats per model.
Lost: nothing seen so far. Added: cheaper rounds (about 1% of a week per round saved, unchecked).
Other option: keep Opus for all rounds.
